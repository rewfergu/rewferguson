## Marketing automation platform for ZoomInfo

Later renamed to just Marketing, MarketingOS is a marketing automation platform that allows users to create and manage marketing campaigns. The platform was built using Angular for the frontend, Node.js and NestJS for the backend, and PostgreSQL for the database. Docker was used to containerize the application for easy deployment.
